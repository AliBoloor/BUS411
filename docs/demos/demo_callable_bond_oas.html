Learning Objectives

After completing this demo you should be able to:

  • value option-free and callable bonds with backward induction;
  • apply the issuer’s call decision at each eligible node;
  • isolate the embedded call option’s price cost;
  • solve for the option-adjusted spread (OAS) that matches a market price; and
  • calculate effective duration and effective convexity by repricing the bond.

2 Build a Recombining Short-Rate Tree

At time \(t\), node \(j\) has short rate

\[ r_{t,j}=m_t\exp\left[(2j-t)\sigma\right], \]

where \(m_t\) is the median-rate path and \(\sigma\) controls annual volatility. Moving up increases \(j\) by one; moving down leaves \(j\) unchanged. Because the same number of up moves leads to the same node, the tree recombines.

Code 
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

face = 100.0
coupon_rate = 0.0525
coupon = face * coupon_rate
maturity = 7
median_rates = np.array([0.0420, 0.0410, 0.0400, 0.0390, 0.0380, 0.0375, 0.0370])
rate_volatility = 0.18
up_probability = 0.50

call_schedule = {3: 101.50, 4: 101.00, 5: 100.50, 6: 100.00}

def build_rate_tree(medians, volatility, parallel_shift=0.0):
    """Return a recombining lognormal short-rate tree."""
    tree = []
    for t, median in enumerate(medians):
        nodes = np.array([
            median * np.exp((2 * j - t) * volatility) + parallel_shift
            for j in range(t + 1)
        ])
        if np.any(nodes <= -1.0):
            raise ValueError("A shocked node rate is below -100%.")
        tree.append(nodes)
    return tree

rate_tree = build_rate_tree(median_rates, rate_volatility)
rate_table = pd.DataFrame({
    f"Year {t}": pd.Series(100 * nodes)
    for t, nodes in enumerate(rate_tree)
}).round(3)
rate_table.index.name = "Node (number of up moves)"

3 Price the Option-Free and Callable Bonds

Values are measured immediately after any coupon at a node. The one-period holding value is

\[ V_{t,j}^{\text{hold}} = \frac{C+pV_{t+1,j+1}+(1-p)V_{t+1,j}} {1+r_{t,j}+s}. \]

For the option-free bond, this holding value is retained. At an eligible call date, the callable bond applies the issuer’s minimum rule:

\[ V_{t,j}^{\text{callable}} = \min\left\{V_{t,j}^{\text{hold}},\text{Call Price}_t\right\}. \]

Code 
def price_bond(rate_tree, spread=0.0, callable_bond=False, return_tree=False):
    """Price the bond by backward induction; node values are ex-coupon."""
    values = np.full(maturity + 1, face, dtype=float)
    value_tree = [None] * (maturity + 1)
    value_tree[maturity] = values.copy()

    for t in range(maturity - 1, -1, -1):
        expected_next = (
            (1 - up_probability) * values[:-1]
            + up_probability * values[1:]
        )
        hold_value = (coupon + expected_next) / (1 + rate_tree[t] + spread)
        if callable_bond and t in call_schedule:
            values = np.minimum(hold_value, call_schedule[t])
        else:
            values = hold_value
        value_tree[t] = values.copy()

    if return_tree:
        return float(values[0]), value_tree
    return float(values[0])

benchmark_straight_price = price_bond(rate_tree, spread=0.0)
benchmark_callable_price = price_bond(rate_tree, spread=0.0, callable_bond=True)
benchmark_option_cost = benchmark_straight_price - benchmark_callable_price

pd.Series({

4 Illustrate and Solve for OAS

To make the exercise reproducible, suppose the callable bond trades at the model value generated by an 85-basis-point spread. We then hide that spread and recover it from the price. In practice, the price would come from the market.

Code 
illustrative_true_oas = 0.0085
market_price = price_bond(
    rate_tree,
    spread=illustrative_true_oas,
    callable_bond=True,
)

def solve_spread(target_price, callable_bond, lower=-0.02, upper=0.10, tolerance=1e-12):
    """Solve a constant spread with robust bisection."""
    price_lower = price_bond(rate_tree, lower, callable_bond)
    price_upper = price_bond(rate_tree, upper, callable_bond)
    if not (price_lower >= target_price >= price_upper):
        raise ValueError("Target price is not bracketed by the spread interval.")

    for _ in range(200):
        midpoint = 0.5 * (lower + upper)
        midpoint_price = price_bond(rate_tree, midpoint, callable_bond)
        if abs(midpoint_price - target_price) < tolerance:
            return midpoint
        if midpoint_price > target_price:
            lower = midpoint
        else:
            upper = midpoint
    return 0.5 * (lower + upper)

solved_oas = solve_spread(market_price, callable_bond=True)
static_spread = solve_spread(market_price, callable_bond=False)
option_cost_spread = static_spread - solved_oas
reprice = price_bond(rate_tree, solved_oas, callable_bond=True)

pd.Series({
    "Illustrative market price": market_price,
    "Solved OAS (bp)": solved_oas * 10_000,
    "Static spread on promised cash flows (bp)": static_spread * 10_000,
    "Option cost in spread terms (bp)": option_cost_spread * 10_000,
    "Repriced callable value": reprice,
}).round(6)

5 Effective Duration and Effective Convexity

Modified duration is not sufficient because the call decision changes across rate paths. Hold OAS fixed, shift the entire benchmark tree by \(\pm\Delta y\), and fully reprice:

\[ D_{\text{eff}} =\frac{P_- - P_+}{2P_0\Delta y}, \]

\[ C_{\text{eff}} =\frac{P_-+P_+-2P_0}{P_0(\Delta y)^2}. \]

Code 
curve_shock = 0.0025  # 25 basis points

def effective_risk(callable_bond):
    base = price_bond(rate_tree, solved_oas, callable_bond)
    down_tree = build_rate_tree(median_rates, rate_volatility, -curve_shock)
    up_tree = build_rate_tree(median_rates, rate_volatility, curve_shock)
    price_down = price_bond(down_tree, solved_oas, callable_bond)
    price_up = price_bond(up_tree, solved_oas, callable_bond)
    duration = (price_down - price_up) / (2 * base * curve_shock)
    convexity = (price_down + price_up - 2 * base) / (base * curve_shock**2)
    return base, price_down, price_up, duration, convexity

straight_risk = effective_risk(False)
callable_risk = effective_risk(True)

risk_table = pd.DataFrame(
    [straight_risk, callable_risk],
    index=["Option-free bond", "Callable bond"],
    columns=["P0", "P(-25 bp)", "P(+25 bp)", "Effective duration", "Effective convexity"],
)
risk_table.round(4)

The callable bond should generally have shorter effective duration because its upside is capped when rates fall. Its effective convexity can also be much lower, or negative, near the region where call exercise changes rapidly.

7 Financial Interpretation

This workflow separates three ideas that a yield-to-maturity comparison mixes together:

  1. The benchmark short-rate tree values state-contingent cash flows.
  2. The minimum rule transfers low-rate upside from the investor to the issuer.
  3. OAS measures the constant spread that remains after the call option has been modeled.

The outputs are model-dependent. A different benchmark curve, volatility, call behavior, or tree calibration can materially change the option value, OAS, effective duration, and effective convexity.

## Financial Interpretation

This workflow separates three ideas that a yield-to-maturity comparison mixes together:

1. The benchmark short-rate tree values state-contingent cash flows.
2. The minimum rule transfers low-rate upside from the investor to the issuer.
3. OAS measures the constant spread that remains after the call option has been modeled.

The outputs are model-dependent. A different benchmark curve, volatility, call behavior, or tree calibration can materially change the option value, OAS, effective duration, and effective convexity.
