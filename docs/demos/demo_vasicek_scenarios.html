Purpose and Assumptions

The Vasicek model is

\[ dr_t=\kappa(\theta-r_t)dt+\sigma dW_t. \]

This demo estimates its parameters from a dated monthly U.S. effective federal funds-rate history, simulates scenarios, checks long-run moments, and uses the fitted distribution for a one-year risk decision. The embedded observations are monthly averages for January 2023 through June 2025, recorded in percent and converted to decimals. Source: Federal Reserve Bank of St. Louis, Effective Federal Funds Rate (FEDFUNDS). Parameters are constant; estimation error, regime shifts, jumps, and term premia are ignored. This short sample is pedagogical and should not be treated as a robust trading calibration.

2 Step 2: Estimate Vasicek parameters

The exact monthly transition can be written as an AR(1):

\[ r_{t+\Delta}=\alpha+\phi r_t+\varepsilon_{t+\Delta},\qquad \phi=e^{-\kappa\Delta},\qquad \alpha=\theta(1-\phi). \]

After OLS estimation,

\[ \widehat\kappa=-\frac{\log\widehat\phi}{\Delta},\qquad \widehat\theta=\frac{\widehat\alpha}{1-\widehat\phi},\qquad \widehat\sigma=s_\varepsilon \sqrt{\frac{2\widehat\kappa}{1-\widehat\phi^2}}. \]

Here \(\Delta=1/12\) year, \(\kappa\) is in \(1/\text{year}\), and \(\sigma\) is in decimal rate units per \(\sqrt{\text{year}}\).

Code 
dt = 1 / 12
x = history.iloc[:-1].to_numpy()
y = history.iloc[1:].to_numpy()
design = np.column_stack([np.ones_like(x), x])
alpha_hat, phi_hat = np.linalg.lstsq(design, y, rcond=None)[0]
residuals = y - (alpha_hat + phi_hat * x)
residual_std = residuals.std(ddof=2)

if not 0 < phi_hat < 1:
    raise ValueError("This sample does not imply a stationary Vasicek fit.")

kappa = -np.log(phi_hat) / dt
theta = alpha_hat / (1 - phi_hat)
sigma = residual_std * np.sqrt(2 * kappa / (1 - phi_hat**2))
r0 = float(history.iloc[-1])

half_life = np.log(2) / kappa
long_run_std = sigma / np.sqrt(2 * kappa)

pd.Series({
    "Current rate": r0,
    "Estimated monthly persistence phi": phi_hat,
    "Mean-reversion speed kappa (1/year)": kappa,
    "Long-run mean theta": theta,
    "Volatility sigma (rate/sqrt(year))": sigma,
    "Mean-reversion half-life (years)": half_life,
    "Long-run standard deviation": long_run_std,
}).round(5)

3 Simulate Monthly Paths

The exact Vasicek transition is normal:

\[ r_{t+\Delta}=\theta+(r_t-\theta)e^{-\kappa\Delta} +\sigma\sqrt{\frac{1-e^{-2\kappa\Delta}}{2\kappa}}Z. \]

Code 
rng = np.random.default_rng(411)

def simulate_vasicek(initial_rate, years, paths, rng):
    steps = int(round(years / dt))
    output = np.empty((steps + 1, paths))
    output[0] = initial_rate
    persistence = np.exp(-kappa * dt)
    innovation_std = sigma * np.sqrt((1 - np.exp(-2 * kappa * dt)) / (2 * kappa))
    for t in range(steps):
        output[t + 1] = (
            theta + (output[t] - theta) * persistence
            + innovation_std * rng.standard_normal(paths)
        )
    return output

paths = simulate_vasicek(r0, years=5, paths=5_000, rng=rng)
time = np.arange(paths.shape[0]) * dt

fig, ax = plt.subplots(figsize=(7.5, 4.1))

Vasicek rates are normally distributed, so negative rates are possible. That can be useful in markets where negative policy rates are plausible, but it may be undesirable for other applications. A positivity-preserving model such as CIR changes this feature, at the cost of a different distribution and dynamics.

Suppose a treasury team wants a one-year planning range for a floating-rate funding cost tied to the overnight rate. 7 Validate Long-Run Moments and Units

The stationary Vasicek distribution has

\[ E[r]=\theta, \qquad \operatorname{Var}(r)=\frac{\sigma^2}{2\kappa}. \]

Code 
long_paths = simulate_vasicek(r0, years=20, paths=30_000,
                              rng=np.random.default_rng(413))[-1]
simulated_mean = long_paths.mean()
simulated_std = long_paths.std(ddof=1)

assert kappa > 0 and sigma > 0

8 Financial Interpretation

Mean reversion makes the expected rate move toward \(\theta\), while volatility keeps future rates dispersed. \(\kappa\) determines how quickly today’s rate loses influence; \(\sigma\) determines scenario width. The model is a disciplined scenario generator, not a forecast guarantee. Calibration window, probability measure, structural breaks, and the normal model’s negative-rate tail all affect how its output should be used.

## Simulate Monthly Paths

The exact Vasicek transition is normal:

$$
r_{t+\Delta}=\theta+(r_t-\theta)e^{-\kappa\Delta}
+\sigma\sqrt{\frac{1-e^{-2\kappa\Delta}}{2\kappa}}Z.
$$

```{python}

rng = np.random.default_rng(411)
```
